Active Flutter Control System for UAS Wing

Aug 2023 - Dec 2023

MATLABSimulinkPID Control Accelerometer FeedbackPiezoelectric Actuators
Project objective: develop and validate a simulated control system that suppresses wing flutter for an unmanned aircraft wing at the required 118.3 km/h airspeed.

Introduction

Wing flutter is dangerous because aerodynamic forces can feed energy into a structure until oscillations grow beyond safe limits. For unmanned aircraft, active control offers a way to extend safe operation without relying only on heavier passive structures. This project tested whether sensor feedback and piezoelectric actuation could suppress flutter in simulation.

Method

I built a control-oriented wing dynamics model in MATLAB/Simulink, then implemented a PID-based controller using accelerometer feedback. Piezoelectric actuators were modeled as the active input that could counter the wing's oscillatory response. Root locus and Bode analyses were used to understand stability margins and tune the controller.

Results

Simulation results showed effective oscillation suppression at the target airspeed. Comparing the controlled and uncontrolled behavior helped confirm that the controller improved damping and kept the response within a safer range. The analysis also showed why frequency-domain validation is valuable for flutter problems: a time response alone does not fully explain stability risk.

My Contribution

  • Developed the MATLAB/Simulink simulation workflow for wing dynamics and active control.
  • Implemented PID control with accelerometer feedback and piezoelectric actuator input.
  • Validated stability using root locus and Bode analysis.
  • Connected simulation results to the practical goal of suppressing flutter at 118.3 km/h.
